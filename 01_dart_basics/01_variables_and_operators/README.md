- Dart program structure
- Variables and data types
- String, int, double, bool

In this class, I learned the basic structure of Dart programs and how to work with variables, data types, and operators.

Key concepts:
- Difference between `var` and `dynamic`
- Difference between `final` and `const`
- Nullable variables using null safety
- Using Dart operators for calculations and conditions
